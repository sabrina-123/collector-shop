# Catalog photos

Place your real photos in the category folders below.
Use JPG, PNG or WebP files. File names may contain spaces.

- pieces-de-monnaie
- poupees-anciennes
- photographie-vintage
- vinyles-musique
- objets-anciens
- arts-decoratifs
- ceramique
- design-mobilier
- publicite-vintage

The catalog displays 25 demo listings per category. It automatically rotates the photos found in each category folder.
If a file is missing, the existing category fallback photo is used.
Recommended image size: at least 900 x 900 px.
